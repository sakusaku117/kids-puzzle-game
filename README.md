# ディノの かんがえる うちゅうぼうけん

6歳向けの知育パズルゲームです。恐竜と宇宙がテーマで、空間認知と順序立てて考える力を育てます。

`index.html` をブラウザで開くだけで遊べます。インストールや通信は不要です。

## 4つのゲーム

| ゲーム | 内容 | 育てる力 |
|---|---|---|
| 🥚 おにもつ はこび | たまごを押して巣まで運ぶ(倉庫番) | 先を読む力・空間認知 |
| 🧩 かたち ぴったん | ブロックを回して影にはめる | 図形の回転をイメージする力 |
| 🤖 ロボット めいれい | 命令を並べて実行し、星を集める | 順序立てて考える力 |
| 🪞 かがみの もよう | 鏡に映したように模様を描く | 対称性・位置関係の把握 |

難易度は「やさしい / ふつう / むずかしい」の3段階、各10レベルで、全120ステージです。ステージは乱数から自動生成し、必ず解けることを確認したうえで、手数の少ない順に並べています。

## 操作

- 矢印キー、スペース、Enter、Backspace で操作します。画面下に、そのゲームで使うキーが出ます。
- `H`: ヒント / `R`: やりなおし / `Z`: ひとつ戻す / `M`: 音のオン・オフ / `Esc`: 前の画面へ

## おうちの方メニュー(Shift + P)

効果音、遊びすぎ防止タイマー、難易度の固定、全レベルの解放、進み具合の確認とリセットができます。

進み具合はブラウザの localStorage(キー: `dino-space-puzzle-v1`)に保存されます。別のブラウザで開くと最初からになります。
